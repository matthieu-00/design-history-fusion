# Source Directory

Use these for live verification (exact dates, designer attributions, typeface names) — never invent specifics that these could confirm.

| Source | Best for | URL |
|---|---|---|
| Fonts In Use | Typeface-in-real-context, filterable by format/industry/period | fontsinuse.com |
| Letterform Archive | Curated movement-level "tables," type-history toolkit, technology timeline | letterformarchive.org |
| Design Reviewed | Scanned artefacts by country/decade, 150 years of coverage | designreviewed.com |
| TM Research Archive | Swiss/International Style, 1970s–90s specifically (Typographische Monatsblätter) | via Domestika writeup, search directly |
| AIGA Design Archive | US communication design artifacts, 1924– | aiga.org / design archive |
| People's Graphic Design Archive | Crowd-sourced, process material, oral histories | peoplesgdarchive.org |
| Cooper Hewitt Graphic Design Collection | Smithsonian-backed object collection | collection.cooperhewitt.org |
| Center for the Study of Political Graphics | 8,000+ social/political posters | politicalgraphics.org |
| Penrose Annuals (1904–1980) | Annual primary-source record of print/design/advertising/typography across the 20th c. | via Museum of Printing |
| Aspen Magazine (1965–71) / Avant Garde (1968–71) | Primary-source periodicals, Herb Lubalin's Avant Garde typeface origin | digitized archives, search directly |

## When to search vs. when to use the bundled files
- **Bundled files (timeline.md, typography-atlas.md)**: movement-level principles, general grid/color/typography traits, category classification. Fine to state directly.
- **Live web_search**: specific typeface names + exact release year + designer + foundry; specific hex/color values attributed to a named campaign; any claim the person will cite, publish, or use to justify a licensing/legal decision; anything that feels like it could be a common misattribution (type history has a lot of these — e.g., conflating similar-era geometric sans faces).
