# Source Directory

Use these for live verification (exact dates, designer attributions, typeface names) — never invent specifics that these could confirm.

## When to search vs. when to use the bundled files
- **Bundled files (timeline.md, typography-atlas.md)**: movement-level principles, general grid/color/typography traits, category classification. Fine to state directly.
- **Live web_search**: specific typeface names + exact release year + designer + foundry; specific hex/color values attributed to a named campaign; any claim the person will cite, publish, or use to justify a licensing decision; anything that feels like it could be a common misattribution (type history has a lot of these — e.g., conflating similar-era geometric sans faces).

## What to load vs what to cite

Cite the historical face (Futura, Helvetica, ITC Avant Garde Gothic). Load the webfont from Google Fonts (fonts.google.com), in the same category. The token sheet names both: the historical face is the reference, and the Google Fonts family is the file. Do not embed files from the archives above. They are for looking and citing.
