Mode 2b · options requested

Nord. Three Deco directions, not three skins.

Art Deco is already named, so this is not an era question. Options were asked for, so nothing is fully built until a direction is picked. Each option below varies intensity and which layer carries the historical signal. At least one avoids the gold-sunburst-on-black party gradient named in anti-slop.md.

Quiet shop

Option 1 — Edge signal

Why this one’s in contention: A checkout-heavy shop may want Deco as a nod, not a costume — period DNA only in dividers and palette, so product photos and forms stay fully contemporary.

Layer summary: Type: modern Source Sans 3 throughout · Color: navy/paper, no metallic · Grid: ordinary responsive product grid · Ornament: one ziggurat hairline as a section divider · Motion: functional fade, 200ms

Option 2 — Cassandre restraint

Why this one’s in contention: Cassandre’s 1927 Étoile du Nord is steel, perspective, and type corralled to the edge — decorative but disciplined, the anti-slop alternative to gold sunburst maximalism.

Layer summary: Type: geometric sans display (Futura family) · Color: night steel + one signal red · Grid: centered vanishing-point hero, type as a poster border · Ornament: star + rails, not a sunburst · Motion: slow ceremonial fade-in

NORD

Option 3 — Ceremony

Why this one’s in contention: If Nord is selling evening goods, the loud luxury register is a legitimate brief — this is the cliché-adjacent option, used deliberately so Options 1–2 can refuse it.

Layer summary: Type: Didone display (Bodoni-class) · Color: black + metallic gold, stated as the Pinterest-famous Deco shorthand · Grid: symmetrical framed sections · Ornament: ziggurat frames and a sunburst used as a divider, kept clear of type · Motion: scale-in reveal

A live session would stop here and wait for a pick (or “combine 1 and 2”). For this repository example, Option 2 is rendered below so the page still includes a full Layer Map / Token Sheet / Accessibility table — not because the other two were silently discarded.

Rationale

The brief asked for options, so the page leads with three directions that differ on intensity and which layer carries Deco — not three palettes. Option 2 is the anti-cliché pick: Cassandre’s 1927 night railway (steel, vanishing point, type at the margin) instead of gold sunburst + black. Type is a geometric sans because that is Deco’s commercial letter, not a costume Didone. Motion stays modern; the ceremony is compositional, not animated glitter.
